# Adil Anwar Portfolio

A responsive, static portfolio for Adil Anwar, focused on QA automation, support experience, web projects, and AI-assisted website work.

## Run locally

Open `index.html` in a browser, or serve this folder with a local web server. A web server is recommended for the contact form.

## Before publishing

- Replace the CV and portrait in `assets/` when Adil provides updated versions. Keep their current filenames or update the references in `index.html`.
- LinkedIn, Naukri, and GitHub links are included in the contact section and footer. Check the Naukri URL while logged out to confirm it opens as a public profile.
- MediHome's six screenshots, gallery, live demo, and repository links are included in the portfolio. The portfolio presents the public JavaScript demo separately from Adil's described local PHP/MySQL/XAMPP version; the linked public repository currently contains the front-end demo.
- Both projects' public links demonstrate their JavaScript user flows; the local versions' PHP/MySQL backend and admin features run through XAMPP.
- The contact form uses FormSubmit and requires the first submission to be confirmed through the email inbox for `adilanwartester95@gmail.com`.
- Technology logos and fonts load from public CDNs; system font and text fallbacks are included.

## Files

- `index.html` — portfolio structure and content
- `styles.css` — responsive layout, visual design, and motion
- `script.js` — navigation, reveal effects, and skill filters
- `assets/adil-anwar.jpg` — current portrait
- `assets/Adil_Anwar_Automation_Testing_Resume.pdf` — current downloadable CV
